👾 Space Invaders (Pygame)A classic 2D Space Invaders arcade game built using Python and Pygame. Shoot down waves of invading alien ships before they reach the bottom of the screen!📖 Table of ContentsAbout the ProjectKey FeaturesTech StackGetting StartedPrerequisitesInstallationRunning the GameHow to PlayGame Logic & ControlsLicense🧐 About the ProjectThis project is a lightweight, pure-Python implementation of the retro arcade game Space Invaders. Built using Pygame, it provides basic game loop controls, player movement, projectile physics, grid collision detection, and score tracking.✨ Key FeaturesClassic Arcade Gameplay: Dodge and destroy waves of descending alien targets.Bullet Limiter: Maximum of 5 active projectiles on screen at a time to keep shooting strategic.Dynamic Grid Movement: Aliens reverse direction and step lower whenever any unit hits the screen boundary.Collision Detection: Instant destruction of alien targets using standard rectangular collision detection.Score Counter: Live tracking of destroyed alien ships rendered directly on-screen.🛠️ Tech StackLanguage: Python 3.xLibrary: Pygame🚀 Getting StartedPrerequisitesPython 3.7 or higher installed on your machine.pip package installer.InstallationClone or download the repository:git clone https://github.com/your-username/space-invaders-pygame.git
cd space-invaders-pygame
Install Pygame:pip install pygame
Running the GameRun the main script using Python:python main.py
🎮 How to PlayLaunch the game to start the loop immediately.Goal: Shoot down all red alien blocks before they lower themselves down to your green defender block.Game Over: If any alien reaches the player's vertical position (player_y), the window closes automatically.🕹️ ControlsKeyActionLEFT ARROWMove player leftRIGHT ARROWMove player rightSPACEBARFire laser bullet (Max 5 active)📄 LicenseDistributed under the MIT License.
